# Team 17 final results

All 210 fits completed on a single NVIDIA H100 80GB GPU. There are 174 held-out score records, comprising 162 learned checkpoints and 12 deterministic seasonal-naive rows. The run used the [published protocol](../../final/PROTOCOL.md). Re-evaluation from the saved weights and the two original ETTh files on CPU reproduced all 174 MAE/RMSE pairs within 0.00024 °C of the archived GPU values.

| File | Contents |
|---|---|
| [Test summary](test_summary.csv) | Mean MAE and RMSE, across-seed SD, parameter count, stopping epoch and elapsed fitting time per configuration. |
| [Scores by seed](test_by_seed.csv) | All held-out scores in the original temperature units, including the six ablation configurations. |
| [Paired error differences](paired_mae_differences.csv) | Transformer minus each main reference on matched test origins. Negative values favor the Transformer. Circular bootstrap block lengths are 96, 168 and 336 hours. |
| [Matched ablations](paired_ablations.csv) | Paired changes when removing window normalization or one encoder layer. |
| [Synthetic shift experiment](simulation.csv) | Paired synthetic results across the same 512 paths, including shift residual and Monte Carlo standard error. |
| [Persistence](last_value_reference.csv) | Last-observation forecasts at each station and horizon. |
| [Validation search](learning_rate_selection.csv) | Both seed-0 candidates at every primary learning setting, including the chosen rate. |
| [First ETTh2 test day](first_etth2_day.csv) | Observed and predicted hourly temperatures for the full-history day-ahead example, seed 0. |
| [Four-day profile](etth2_error_by_day.csv) | ETTh2 full-history 96-hour MAE by day, averaged over leads and seeds. |
| [Loss traces](etth1_loss_traces.csv) | ETTh1 day-ahead Transformer training and validation losses used in the report supplement. |
| [Run manifest](manifest.json) | Software and hardware versions and input and implementation checksums. |

In the 12 primary cells, normalized linear ranks first in 11 and LSTM in one. Normalized Transformer beats seasonal naive in 9 of 12 by mean MAE. The results archive generated by the [runner](../../run_final.py) additionally contains every scored checkpoint and every origin/lead diagnostic.
